NEWS ONE TELEPROMPTER - COMPLETE GITHUB REPLACEMENT
====================================================
This package restores the October 6 working teleprompter with an enhanced Story Library.
The original narration, rotation, speed, font size, countdown, and Bluetooth code is preserved.

Upload to repository ROOT (not into a new subfolder):
index.html
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png
icons/icon-192.png
icons/icon-512.png

In GitHub: Add file > Upload files, drag the contents (including icons folder),
then Commit changes. Wait for GitHub Pages deployment.

Open this URL directly in Chrome to verify the new version:
https://sundayschooldallas.github.io/news-one-teleprompter/index.html?release=restored-story-library-20261020

The header should say RESTORED STORY LIBRARY.
If the old installed app remains, close it, load the link in Chrome online,
then reopen the installed app. Do NOT clear browser/site data without exporting
stories first: saved stories live in browser localStorage and could be lost.

Story Library: enter title + content, SAVE STORY, MY STORIES, OPEN STORY.
Download Story Backup regularly; data is not synced across devices.

The ZIP contains an original unmodified backup outside the GitHub upload folder.
